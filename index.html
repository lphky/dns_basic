4.1.3 DOMAIN NAME

名稱比數字，更容易記住

網站除了使用 IP 位址，亦可透過容易記憶的網域名稱存取。先點一下每個部分，試試由右向左讀。

先點選 hk：最右邊的標籤就是頂級域。

層級閱讀方向：www ← edb ← gov ← hk（從右邊開始）

一般頂級域

.com 商業 · .edu 教育 · .gov 政府
.org 組織 · .mil 軍事 · .net 網絡

以上為常見或歷史用途；個別域有註冊限制。不同國家或地區的機構也可使用 .com 等一般頂級域。

國家碼頂級域

.hk 香港 · .cn 中國
.jp 日本 · .uk 英國

在 example.com.hk 中，hk 才是頂級域；com 是第二層分類，不能因為字樣相同就當成頂級域。

    再想深一點：全球只有一部 DNS 嗎？

    DNS 是分散式系統。查詢可能利用快取，也可能涉及多個 DNS 伺服器。一個網域可對應多個 IP，記錄也可能更新；這裏以簡化流程集中示範概念。

    4.1.5 UNIFORM RESOURCE LOCATOR

    URL：資源的完整位置

    劃一資源定位（URL）指出網頁或檔案的位置。點選以下四個區段：

    點一下 https://，認識所使用的協定。

    完整 HTTP／HTTPS URL 包含協定及主機名稱；首頁例如 https://www.example.com/，可以沒有明顯的資料夾或檔案名稱。

    路徑一定是真正的資料夾嗎？

    不一定。此例採傳統資料夾／檔案表示方式；現代網站的路徑也可能由程式處理。DNS 只查詢主機名稱，不查詢整條路徑。

    任務：使用 HTTPS，前往 www.example.com 的 storybooks 資料夾，取得 harry-potter.html。

    點號分隔網域標籤；斜線分隔路徑部分。www 並非協定，亦不是所有網站都必須有。
