# DNS Detective｜網域名稱偵探

繁體中文中學電腦科互動教材，涵蓋 4.1.3 網域名稱、4.1.4 DNS 及 4.1.5 URL。參考 https://lphky.github.io/ipv4_basic/ 的教學節奏。

- 網域由右向左逐層拆解與三題引導練習。
- DNS 逐步／自動播放，包含成功與查無記錄情境。
- URL 區段探索與網址組合。
- 24 題題庫每輪抽 10 題（網域 4、DNS 3、URL 3），教師手動揭曉及逐題檢討。
- 觸控、鍵盤、投影大字模式及減少動畫設定。

直接開啟 index.html 即可使用；無框架、外部依賴、後端或個人資料收集。LocalStorage 只記錄大字模式偏好。
